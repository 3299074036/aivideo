## FFmpeg（M1 已集成）

- **组件**：FFmpegKit Android 封装 + FFmpeg 原生库
- **来源**：社区维护分支 [`ffmpegkit-maintained/ffmpeg`](https://github.com/ffmpegkit-maintained/ffmpeg)
  （原 `arthenica/ffmpeg-kit` 已于 2025 年 4 月归档停更；分支保持同 API/包名 `com.arthenica.ffmpegkit`）
- **Maven 坐标**：`dev.ffmpegkit-maintained:ffmpeg-kit-full:8.1.7`（Maven Central）
- **许可证**：**LGPL-3.0**（非 `-gpl` 变体，不含 x264/x265 等 GPL 编码器）
- **合规做法**：
  - AAR 动态链接（满足 LGPL 动态链接要求）
  - App 内「开源许可」页署名（M6 设置页落地）
  - 提供 FFmpeg 源码获取方式说明（指向上游仓库）
  - App 本体可保持闭源
- **禁止**：`-gpl` 变体（`ffmpeg-kit-full-gpl` 等，含 x264/x265）为 GPL-3.0，
  链接后整个 App 必须 GPL-3.0 开源——本工程严禁引入
- **第三方组件保留其原始许可证**：AAR 内 `THIRD-PARTY-NOTICES.txt`
 （运行时可通过 `context.assets.open("THIRD-PARTY-NOTICES.txt")` 读取）
- **16KB 页对齐**：该分支 CI 强制 `-Wl,-z,max-page-size=16384`，
  满足 Google Play 2025-11 起的 16KB 内存页要求

## sherpa-onnx（M2 已集成）

- 来源：[`k2-fsa/sherpa-onnx`](https://github.com/k2-fsa/sherpa-onnx) 官方发布的 Android AAR

- 许可证：**Apache-2.0**，可商用

    phonemizer，`espeak-ng-data/` 是必需参数（`data_dir`），无可绕开的配置

## yt-dlp（M6 已集成框架）

- 来源：[`yt-dlp/yt-dlp`](https://github.com/yt-dlp/yt-dlp)
- 许可证：**Unlicense**（公有领域式，非 GPL，无传染性）
- 合规风险不在许可证，而在平台服务条款：仅用于公开可访问内容，
  App 内显著位置版权提示，不做付费墙/DRM/登录态绕过
- 集成方式（M6，调研结论见 `yt-dlp集成调研.md`）：
  - 官方无 Android 可用原生二进制（`yt-dlp_linux_aarch64` 为 glibc 构建，
    bionic 跑不了）；路线 = **bionic 版 CPython 解释器随 APK 内置** +
    **官方 `yt-dlp` zipimport 纯 Python 归档运行时按需下载**（约 2.9MB，
    不进 APK）+ ProcessBuilder 调用
  - 独立更新通道：GitHub releases API（stable/nightly 双通道）→ tag 比对 →
    下载归档 → SHA-256 校验 → 原子替换 → 失败回滚；与 APK 发版解耦
  - **NewPipeExtractor 依然严禁**（GPL-3.0）；`youtubedl-android` 库
    本身也是 GPL-3.0 且是第三方依赖——只借鉴其架构，不引入
  - 状态：框架代码 + 更新通道 + 批量下载 UI 已实现（单元测试覆盖）；
    **Python 解释器二进制尚未内置**（交叉编译配方见调研文档 §6.2），
    界面缺失时明确提示；端到端下载待解释器就绪后真机验证
