## 一、完成了什么

1. **新工程脚手架** `~/workspace/7Z1H/codes/aivideo/`
   - 包名 `com.zola.aivideo`，App 名「影译」（provisional，可改），versionName 0.1.0
   - 技术栈：Kotlin + Compose（M3 Expressive）+ Hilt + Room + Navigation Compose + DataStore（依赖已接）
   - minSdk 26 / targetSdk 35 / compileSdk 36；`abiFilters` 仅 `arm64-v8a`
   - 23 个 Kotlin 文件：`AiVideoApp`、`MainActivity`、theme（`Theme`/`Color`/`Type`）+

     首页（导入入口 + 显著版权提示）、导入流程（`ImportViewModel` + `ImportResultScreen`）、
     `MediaMetadataReader`（MediaExtractor 精确检测音轨/字幕轨）、`FFmpegService` +

2. **FFmpeg 集成验证**
   - `dev.ffmpegkit-maintained:ffmpeg-kit-full:8.1.7`（Maven Central 解析成功，未触发降级方案）
   - LGPL-3.0 构建，**未引入任何 `-gpl` 变体**（NewPipeExtractor 同样零引入）
   - APK 内 `lib/arm64-v8a/` 含全部 ffmpegkit .so；readelf 抽查全部 .so 的 LOAD 段
     p_align 均为 `0x4000`（16KB），满足 Play 2025-11 起的 16KB 页要求
   - `FFmpegService.getVersion()` / `executeAsync` / cancel 封装完成，API 可调用
3. **本地视频导入 + 元信息页**
   - 系统文件选择器（video/*）→ 复制到 `filesDir/imports/` → 元信息页
   - 展示：分辨率、时长、大小、格式、音频轨/内嵌字幕轨有无；无音频轨时明确提示后续功能不可用
   - 状态机：复制中 → 读取中 → 成功 / 失败（原因 + 重试按钮），无白屏干等
   - 首页首屏显著位置版权提示 Card："仅处理您拥有权利或已获授权的视频；下载他人视频可能违反平台条款与著作权法，后果自负"

## 三、已知问题

1. **FFmpeg 原生执行未验证**：沙箱是 x86_64 Linux，APK 只打 arm64-v8a（按任务要求），无法在沙箱内跑转码。
   真机验证步骤（用户侧）：装 `aivideo-debug-0.1.0.apk` → 诊断方式调用 `FFmpegService.getVersion()`（M2 会在设置页加"FFmpeg 版本"展示行）→ 跑一次 `buildExtractPcmWav` 抽音频。
2. **构建期偶发外部干扰**：首次构建被并行的 videonotes 构建 `./gradlew --stop` 中断（"stop command received"），
   第二次因共享 `GRADLE_USER_HOME` journal 锁等待超时；属多任务并行构建的已知现象，重试即过，非工程问题。
   建议：同一 GRADLE_USER_HOME 下避免多工程同时构建。
3. **导入页细节**：`ImportResultScreen` 重试按钮图标与文字间距用 padding 占位，视觉可接受但不够精致，M6 UI 打磨时统一处理。
4. **未做**（按计划在后续里程碑）：链接下载（yt-dlp）、ASR/TTS（M2/M4）、任务中心状态机（M5）、设置页（M6）。
