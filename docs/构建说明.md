## 三、构建步骤

脚本一共四步，按顺序执行：

1. **定位工具链**：依次检查 `tools/jdk-17`、`tools/android-sdk`（缺失则报错退出，不自行安装——安装目录变更需用户审批）。
2. **导出环境变量**：
   - `JAVA_HOME`、`ANDROID_HOME`、`ANDROID_SDK_ROOT`、`GRADLE_USER_HOME`、`PATH`、`_JAVA_OPTIONS="-Djava.net.preferIPv4Stack=true"`
   - 代理：沙箱无直连出口，Gradle Wrapper 启动的 JVM 不读 `gradle.properties`，脚本用 `GRADLE_OPTS` 显式传入 `-Dhttp/https.proxyHost/Port`（代理无需认证）。
3. **构建**：`./gradlew assembleDebug --no-daemon`（工程内 Wrapper）
4. **产物归档**：
   - 从 `app/build.gradle.kts` 读取 `versionName`
   - 产物复制到 `apps/aivideo/aivideo-debug-<versionName>.apk`
   - 仅保留最新 3 个产物

## 四、注意事项

1. **不要并行构建**：同一 `GRADLE_USER_HOME` 下两个工程同时构建会报 journal 锁冲突——错开时间。
2. **代理 CA 轮换**：沙箱出口走 MITM 代理，CA 会轮换；新装 JDK 必须把当前代理 CA 导入其 cacerts（从实时链里取）。
3. **签名**：debug 包用 `codes/keystores/aivideo-debug.keystore`，同名覆盖可直接覆盖安装。
4. **手动构建命令**（不走脚本时）：
   ```bash
   export JAVA_HOME=~/workspace/7Z1H/tools/jdk-17
   export ANDROID_HOME=~/workspace/7Z1H/tools/android-sdk
   export ANDROID_SDK_ROOT=$ANDROID_HOME
   export GRADLE_USER_HOME=~/workspace/7Z1H/dependencies/gradle-home
   export _JAVA_OPTIONS="-Djava.net.preferIPv4Stack=true"
   cd ~/workspace/7Z1H/codes/aivideo
   ./gradlew assembleDebug --no-daemon
   ```
